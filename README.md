# 다중 방언 언어학습 플랫폼

## 지원 언어
- 민난어 (민어)
- 광둥어 (입석)
- 투바어 (Тувинский)
- 영국식 영어 (British English)
- 인도식 영어 (Indian English)
- 제주어 (Jeju)
- 슈바이츠 독일어 (Schweizerdeutsch)
- 오스트리아 독일어 (Österreichisches Deutsch)

## 기술 스택
- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL

## 설치 방법
1. npm install
2. .env 파일 설정
3. npm run dev

## 기능
1. 사용자 인증
2. 레슨 관리
3. 어휘 학습
4. 발음 연습
5. 진행도 추적
